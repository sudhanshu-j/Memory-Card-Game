# Memory Card Game 🃏🧠

Welcome to the **Memory Card Game** repository! 🎉 This is a classic memory game where the goal is to match pairs of cards. The game challenges your memory and tests how quickly you can match the cards before the timer runs out ⏱️.

---

## Features 🌟

- **Card Flipping**: Click on cards to reveal their faces. Try to match pairs of cards.

- **Timer**: The game includes a countdown timer ⏳. You have a limited amount of time to match all pairs.

- **Flips Counter**: The number of times you flip a card is tracked.

- **Shuffle Mechanism**: Cards are shuffled randomly after each game restart 🔀.

- **Mobile Responsive**: The game works on both desktop and mobile devices 📱💻.

- **Shake Animation**: Mismatched cards shake briefly before flipping back 🌀.

- **Refresh Button**: Restart the game with a click of a button 🔄.

---

## Game Instructions 📝

1. **Start the Game**: The game begins with the cards shuffled face down.

2. **Flip Cards**: Click on any card to flip it. Once you flip two cards, the game checks if they match.

3. **Matching Cards**: If the two flipped cards match, they will stay face up.

4. **Keep Flipping**: Continue flipping the cards to match all the pairs.

5. **Game Over**: The game ends when either:
   
   - You match all 8 pairs before time runs out ⏰.
   
   - The timer hits zero ⌛.

The game tracks the number of flips and displays the remaining time on the screen.

## Technologies Used 🛠️

- **HTML**: For the structure and layout of the game.

- **CSS**: For styling and animations, including the flip and shake effects.

- **JavaScript**: For game logic, such as card flipping, checking for matches, tracking time, and managing the game state.

- **Google Fonts**: For font styling (Poppins font family).

---

## Files in this Repository 📂

### 1. `index.html`

This is the main HTML file containing the game structure, including the card layout, timer, and flip logic.

### 2. `style.css`

The CSS file provides the styling for the game, including animations for card flips and shakes, as well as the layout and color scheme.

### 3. `script.js`

This JavaScript file manages the core functionality of the game. It includes the timer, flip logic, card matching, shuffle functionality, and the refresh mechanism.

---

## Game Flow 🚶‍♂️

1. **Initialization**: 

   - The cards are shuffled.

   - The timer starts when the first card is clicked.
   
3. **Card Flip**:

   - When a card is clicked, it flips to reveal the image on the back.

   - If two cards are flipped, the game checks for a match.
   
5. **Match Handling**:

   - If the two cards match, they stay face up.

   - If the cards don't match, they shake briefly before flipping back down.
   
7. **Game Completion**:

   - Once all pairs are matched, or if the timer reaches 0, the game stops.

---

## How to Play 🎮

1. Clone or download this repository to your local machine.

2. Open the `index.html` file in your browser.

3. The game will automatically shuffle and start. Use the mouse or touch to flip cards.

4. Try to match all pairs before the timer runs out! ⏱️

5. Press the **Refresh** button to restart the game 🔄.
